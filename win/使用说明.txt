锦鲤池 v0.3.10 — Windows 桌面动态壁纸
====================================

空闲巡游不再频繁打出可见尾浪；点击投喂仍有明显水花。
托盘可打开设置、改天色/天气、投喂、重新贴上、退出（TrayHost）。
选「自动」则跟真实时钟。壁纸模式会显示设置齿轮。
天色和天气会渐变，不再瞬间切换（雨下起来/停、昼夜也是过程）。
切到白天晴天时，焦散和水面高光跟着同一段渐变亮起来，不会突然弹出。
雨是俯视细丝（更陡、比 v0.3.8 更快、若隐若现、尖端收细），落到水面只按大小打涟漪，不再出现大白雨点。
阴/雾/雨切到晴天不再靠 2D 全屏罩层，避免桌面宿主上的马赛克。
已撤销 v0.3.3 的同心圈叠层和按游速改摆尾。

下载后如何变成桌面背景
----------------------
1. 解压整个文件夹，不要只抽 exe。
2. 双击 koi-pond-wallpaper.exe（或「设为桌面壁纸.bat」）。
3. 程序会把锦鲤池嵌到桌面图标后面，成为真正的动态壁纸，不是普通全屏窗口。
4. 右下角托盘：打开设置、投喂、天色/天气预览、重新贴到桌面、用 Lively 设壁纸、退出。
   桌面上的浅色齿轮也可开设置，当场切换昼/夜/雨/雾。选「自动」则跟真实时钟。

系统要求
--------
- Windows 10 1809+ 或 Windows 11，64 位
- Microsoft Edge WebView2 Runtime（Windows 11 一般已自带；Win10 若白屏请安装：
  https://developer.microsoft.com/microsoft-edge/webview2/ ）
- 不必另装 .NET（本包自包含）
- 不必安装 Lively。直接贴桌面失败时，可安装免费的 Lively Wallpaper 再运行，
  程序会尝试写入图库并设为壁纸：
  https://github.com/rocksdanister/lively/releases

若没能贴到图标后面
------------------
程序不会自动改成全屏窗口。会弹出选择：再试一次贴桌面 / 用或安装 Lively / 仅窗口预览 / 退出。
「窗口预览」只是看效果，不是桌面背景。

命令行
------
（默认）          设为桌面动态壁纸
--lively          优先用本机 Lively 设壁纸
--window / -w     仅窗口预览（不是桌面背景）

源码 / 浏览器 / 手动 Lively
---------------------------
